# SoundCraft Protocol 002 – The SoundCraft Audio Stamp / Metadata Tag

**Purpose:**  
To specify the audible and metadata elements that certify an official SoundCraft Composition.

—

## 1. Audible Stamp
- **Chime Sequence:** 528 Hz → 963 Hz → 639 Hz  
- **Voice Line:** “This has been a SoundCraft Composition.”  
- **Placement:** As defined by Protocol 001 (ends 3.14 s before track end).
To be considered: [  
- **Amplitude:** ≈ –22 LUFS  
- **Reverb:** 20–30 % wet blend.  
- **Stereo Position:** center-panned, light diffusion. ]

—

## 2. Metadata Tag
Embedded fields within master WAV and project files:

Produced by: SoundCraft Composer
Creative Signature: “Forged in Light”
Audio Stamp ID: SC-{YYYY}-{XX}-{NNN}
Protocol: {##} / {Protocols_Total} Compliant

—

## 3. Duration
3.0–3.5 s recommended. Longer tags permitted only for ceremonial or live editions.
