The [Frequency Library/ directory on `main`](https://github.com/Schizo-Studios-509/SoundCraft-Master-Hub/tree/main/Frequency%20Library) contains the authoritative SoundCraft frequency entries and interpretive associations.

[Pull request #4](https://github.com/Schizo-Studios-509/SoundCraft-Master-Hub/pull/4), merged October 31, 2026, removed six duplicate paths while preserving 19 canonical frequency records.

Website documentation is curated selectively from `main`. Preserve source wording and provenance, and distinguish acoustic definitions from symbolic interpretations when publishing frequency references.
